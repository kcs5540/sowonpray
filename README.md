# 소원기도 (SowonPray) - 모바일 신행 & 포교사 전산 플랫폼

## 1. 프로젝트 개요 & 비즈니스 구조
- **공식 서비스명**: **소원기도 (SowonPray)** (전국 모바일 신행도량 플랫폼)
- **1호 공식 도량**: 제주 소원사 (`sowonpray.vercel.app`)
- **사찰 측 파트너**: **양영문 회장 (제주 소원사 창건주 & 신도회장)**
- **주관/운영 총괄**: **제주AI파트너 (대표 김철수)**
- **핵심 목표**: 
  - 신도용: 모바일 '소원 한 줄 인연 축원' (무료 축원 접수 및 사시예불 축원 보고 알림톡)
  - 포교사용: 10인 포교사 고유 추천 링크 발급 및 산하 신도 인연 락인(1년) 관리
  - 비즈니스: 생전예수재 및 영구위패(200만원) 봉안 유치와 수당 50% 자동 정산

## 2. 수당 배분율 (총 50% 풀, GEMINI.md 기준)
- **1대 (직접 권선자)**: 30% (위패 기준 60만 원)
- **2대 (상위 추천자)**: 10% (위패 기준 20만 원)
- **3대 (간접 추천자)**: 5% (위패 기준 10만 원)
- **★ 김철수 대표 (마케팅 총괄/플랫폼 운영)**: **5% (위패 기준 10만 원 고정 오버라이딩)**
- ※ 소원사 사찰 귀속: 50% (위패 기준 100만 원)

## 3. 기술 스택
- **프론트엔드**: Vite + React / 모던 반응형 웹앱 (스마트폰 최적화 PWA/웹앱)
- **데이터베이스/백엔드**: 수파베이스 (Supabase - RLS 멀티 테넌트)
- **알림톡 연동**: 카카오 비즈니스 알림톡 (알리고/솔라피 API)
- **호스팅**: Vercel (`sowonpray.vercel.app`)
